<h2 align='center'>Clink.py</h2>
Clink is a small web crawler that was born to search for comments in a given webpage.
It has few features now thanks to various CTFs:

1. search for comments
2. search for links
3. search for patterns
4. search the above recursively ( same domain)
5. output to a file

Usage:

    python3 clink.py -u URL [-r RECURSE] [-c COMMENTS] [-w PATTERN] [-l LIST LINKS] [-s SAVEFILE]
